# Y & A — ربات سرگرمی گروهی تلگرام

نسخه آماده Railway با Python 3.10+ و python-telegram-bot.

## امکانات
- جرئت یا حقیقت نوبتی در گروه با دکمه‌های درون‌رباتی
- دسته‌بندی سؤال‌ها و افزودن دسته جدید از پنل ادمین
- سنگ کاغذ قیچی دو نفره در گروه
- امتیاز، سطح و جدول رتبه‌بندی هر گروه
- ثبت کاربران و گروه‌ها در SQLite
- پنل ادمین خصوصی برای مدیریت دسته‌ها، سؤال‌ها و آمار
- دستورهای فارسی و بدون `/` برای بازی‌های متنی
- callbackهای امن برای دکمه‌ها و جلوگیری از دوباره‌کاری
- پاک‌سازی خودکار بازی‌های منقضی‌شده

## اجرا
1. `.env.example` را به `.env` تبدیل کنید.
2. `BOT_TOKEN` و `ADMIN_IDS` را وارد کنید.
3. `pip install -r requirements.txt`
4. `python main.py`

## Railway
Repository را به Railway متصل کنید و Variables زیر را بسازید:
- `BOT_TOKEN`
- `ADMIN_IDS`
- `DB_PATH` اختیاری

Start Command: `python main.py`

## دستورهای اصلی
در گروه:
- `بازی` — منوی بازی‌ها
- `جرئت حقیقت` — شروع بازی
- `سنگ کاغذ قیچی` — شروع بازی دو نفره
- `امتیاز` — امتیاز شما
- `رتبه بندی` — جدول گروه

در چت خصوصی:
- `استارت`
- `امتیاز`
- `راهنما`
- `پنل مدیریت` (فقط ادمین)

برای جلوگیری از تداخل با پیام‌های عادی، ربات فقط عبارت‌های دقیق بالا را فرمان تلقی می‌کند.
